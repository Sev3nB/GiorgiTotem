# GiorgiTotem — Chiosco Informativo Scolastico

> **Framework:** .NET / C#  
> **Ambito:** Progetto Scolastico (I.T.T. "E. Giorgi" — Brindisi)

Applicazione desktop interattiva sviluppata per la gestione di un totem/chiosco informativo touch-screen destinato agli studenti, ai docenti e ai visitatori dell'Istituto Tecnico Tecnologico "E. Giorgi".

---

## Caratteristiche del Software

- **Interfaccia Touch Friendly:** Pulsanti e componenti UI sovradimensionati per la navigazione su schermo tattile.
- **Mappa & Indicazioni:** Consultazione rapida della disposizione delle aule e dei laboratori dell'istituto.
- **Bacheca Informativa:** Sezione dedicata alle circolari, agli eventi scolastici e agli orari.
- **Logica Modulare:** Codice strutturato in C# orientato agli oggetti per una facile manutenzione.

---

## Tech Stack

- **Linguaggio:** C#
- **Piattaforma:** .NET Framework / .NET Core
- **IDE:** Microsoft Visual Studio

---

## Come Compilare ed Eseguire

1. Apri il file di soluzione (`GiorgiTotem.sln`) con **Visual Studio 2022** (o superiore).
2. Verifica la presenza del workload per lo sviluppo desktop .NET.
3. Seleziona la configurazione `Debug` o `Release`.
4. Premi `F5` o clicca su **Avvia** per compilare ed eseguire l'applicazione.
